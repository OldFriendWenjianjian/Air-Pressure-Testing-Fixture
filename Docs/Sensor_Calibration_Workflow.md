# 压力传感器校准流程

## 1. 目标

本流程用于在 Qt 调试模式下完成压力传感器的零点加三点校准。阀动作、采样、曲线校验和 Flash 保存均由 MCU 完成；Qt 只负责选择模式与目标位置、发送按压状态，以及提交人工标准表读数。

每个逻辑位置保存一条独立的四锚点曲线：

- 点 0：零点，记录值固定为 `0mmHg`；不要求先执行 VENT，也不受 `ZeroReady` 限制。
- 点 1：第一标定点，由用户填写外部标定计当前实测值，无预设压力。
- 点 2：第二标定点，由用户填写外部标定计当前实测值，无预设压力。
- 点 3：第三标定点，由用户填写外部标定计当前实测值，无预设压力。

协议字段和单位见 `PC-MCU_USB_Control_Protocol.md`。

## 2. 两种校准模式

### 2.1 借用 IIC1 工位

协议 `ENTER` 使用 `Mode=0`，`DestinationSlot` 可选 `1` 至 `14`。

- 校准源固定为压力检测1，即 MCU IIC index 0。
- 被校传感器必须接在 IIC1 工位，并使用罐1气路。
- 充气打开阀1；微量放气和自动 VENT 打开阀21；阀2保持关闭。
- 四点数据只允许保存到进入模式时选定的目标位置。
- 保存到其他位置表示该传感器校准完成后将安装到对应逻辑位置；运行模式按逻辑位置加载曲线。

此模式适合在一个固定工位依次校准多个待装传感器。

### 2.2 原位校准

协议 `ENTER` 使用 `Mode=1`，源位置和保存位置均为 `DestinationSlot`，范围为 `1` 至 `14`。MCU 只扫描校准气路需要的传感器，避免无关 IIC 读取影响采样窗口。

罐体传感器原位气路：

| 位置 | 压力源 | 充气点动 | 放气点动/自动 VENT | 保持关闭 |
|---:|---|---|---|---|
| 1 | 压力检测1 | 阀1 | 阀21 | 阀2 |
| 2 | 压力检测2 | 阀3 | 阀22 | 阀4 |
| 3 | 压力检测3 | 阀5 | 阀23 | 阀6 |
| 4 | 压力检测4 | 阀7 | 阀24 | 阀8 |
| 5 | 压力检测5 | 阀9 | 阀25 | 阀10 |
| 6 | 压力检测6 | 阀11 | 阀26 | 阀12 |

通道传感器原位气路：

| 位置 | 压力源 | 通道阀 | 充气路径 | 放气点动/自动 VENT 路径 | 安全监测 |
|---:|---|---:|---|---|---|
| 7 | 压力检测7 | 阀13 | 阀1 + 阀2 + 阀13 | 阀21 + 阀2 + 阀13 | 压力检测1和压力检测7 |
| 8 | 压力检测8 | 阀14 | 阀1 + 阀2 + 阀14 | 阀21 + 阀2 + 阀14 | 压力检测1和压力检测8 |
| 9 | 压力检测9 | 阀15 | 阀1 + 阀2 + 阀15 | 阀21 + 阀2 + 阀15 | 压力检测1和压力检测9 |
| 10 | 压力检测10 | 阀16 | 阀1 + 阀2 + 阀16 | 阀21 + 阀2 + 阀16 | 压力检测1和压力检测10 |
| 11 | 压力检测11 | 阀17 | 阀1 + 阀2 + 阀17 | 阀21 + 阀2 + 阀17 | 压力检测1和压力检测11 |
| 12 | 压力检测12 | 阀18 | 阀1 + 阀2 + 阀18 | 阀21 + 阀2 + 阀18 | 压力检测1和压力检测12 |
| 13 | 压力检测13 | 阀19 | 阀1 + 阀2 + 阀19 | 阀21 + 阀2 + 阀19 | 压力检测1和压力检测13 |
| 14 | 压力检测14 | 阀20 | 阀1 + 阀2 + 阀20 | 阀21 + 阀2 + 阀20 | 压力检测1和压力检测14 |

通道原位校准借用罐1提供压力并通过阀2接到选定通道。任一时刻只允许一个充气或放气动作，切换方向前 MCU 会先关闭校准气路。

## 3. 标准操作顺序

1. 确认标准压力表、被校传感器和气管连接正确。
2. 在 Qt 中选择“借用IIC1工位”或“原位校准”，再选择目标压力检测位置。
3. 点击“进入校准模式”。MCU 关闭全部阀并锁定本次模式和目标位置。
4. 保持所有点动按钮松开，等待 MCU 收满 16 个新样本，然后可直接点击“记录零点”。需要主动泄压时可选用“VENT至零压”，但它不是记录零点的前置条件。
5. 记录零点后，按住充气按钮接近第一个标定压力，松开后可用微量放气调整。压力稳定后输入外部标定计实测值并记录点 1。
6. 按相同方法依次记录点 2 和点 3。三个非零实测值必须逐点升高。
7. 检查四行原始计数和记录值均已显示，再点击写入目标位置。
8. 查询校准状态，确认 `CalibratedMask` 对应位为 1，其他模式显示该位置“已校准”。
9. 点击“退出并关阀”。离开页面、停止流程或通信异常时也必须由 MCU 关阀。

重新记录某一点会覆盖本次暂存点。清空本次采样只清除 RAM 暂存；清除所选位置标定会更新 Flash，并使该位置恢复“未校准”。

## 4. 点动租约和自动 VENT

点动不是无限期开阀：

- Qt 在鼠标按下时发送 `JOG`，租约为 `500ms`。
- 按住期间 Qt 每 `150ms` 续租。
- 鼠标松开立即发送 `STOP`。
- MCU 最多接受 `500ms` 的有效租约；续租停止后 MCU 自动关阀并报告 lease expired。
- 进入、退出、停止、状态切换、超压或异常清场时 MCU 都必须关闭校准阀。

自动 VENT 使用当前模式对应的放气路径。所有气路监测传感器的 nominal 压力连续 `1000ms` 不高于 `1.000mmHg` 后，MCU 停止放气并置位 `ZeroReady`。最长等待 `30000ms`，超时后关阀。`ZeroReady` 只表示 VENT 完成状态，不限制记录零点。

充气期间 MCU 使用 `max(校准压力, nominal压力)` 作为安全压力。任一气路监测值达到 `295.000mmHg` 时停止充气并自动转入 VENT，避免错误曲线掩盖超压。非零标定点必须低于该硬限制。

## 5. 四点曲线

完整曲线必须满足：

```text
raw0 < raw1 < raw2 < raw3
pressure0 = 0 < pressure1 < pressure2 < pressure3
```

相邻 raw 至少相差 `1000` counts，相邻压力至少相差 `1.000mmHg`。MCU 使用 64 位中间值做分段线性换算并四舍五入：

- raw 不高于 raw0 时输出 `0mmHg`。
- raw 位于两个锚点之间时使用对应线段插值。
- raw 高于 raw3 时沿最后一段外推。
- 最终结果限制在 `0mmHg` 至 `300.000mmHg`。

未校准位置继续使用 MPRLS nominal 换算。校准状态和传感器有效状态是两个独立概念：“未校准”不等于“未连接”，“已校准”也不能覆盖传感器故障。

## 6. Flash 持久化

14 个位置的曲线保存在 STM32 内部 Flash 的 A/B 镜像页：

| 页面 | 地址范围 | 大小 |
|---|---|---:|
| A | `0x0807F000` 至 `0x0807F7FF` | 2KB |
| B | `0x0807F800` 至 `0x0807FFFF` | 2KB |

每个镜像包含 magic、schema、sequence、14 槽曲线、有效 mask、CRC32 和最后写入的 commit 标记。保存或清除时，MCU 擦写非活动页、写入 commit、回读校验，再用较新的 sequence 选择新页。掉电发生在新页完成前时，旧页仍可恢复。

固件链接区必须结束于 `0x0807EFFF`。烧录脚本只能擦除固件占用的页，禁止使用 mass erase 或 full-chip erase，也不得把 HEX/BIN 内容写入 `0x0807F000` 至 `0x0807FFFF`。固件更新后应查询 `CalibratedMask`，确认原有校准记录仍在。

若维修恢复明确执行了全片擦除，必须将 14 个位置全部视为未校准，并在重新投入生产前完成所需位置的校准。

## 7. 状态确认与异常处理

- `GET_SENSOR_CAL_STATUS` byte 2 bit2 为 0 表示借用 IIC1 工位，为 1 表示原位校准。
- byte 6 是当前目标位置或查询的已保存位置，使用一基编号 `1` 至 `14`。
- `STATUS_SNAPSHOT` offset 961 的 14 位 mask 用于所有其他页面显示“已校准/未校准”。
- `StorageFault` 置位时显示故障告警，但允许再次保存或清除以重写 inactive 页；只有 MCU 返回成功后才可宣称修复完成。
- `SourceValid=0` 或 `SourceFault=1` 时禁止充气和记录；仍应允许安全放气。
- `NotEnoughSamples` 表示停止阀动作后的新样本不足 16 个，等待实时状态刷新后重试记录。
- `ProfileInvalid` 表示 raw 或人工实测值不递增、跨度不足、点未采齐，或保存位置与进入时目标不一致。
